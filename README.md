# Radio Project

Java program that simulates a radio using interfaces.

## Components
- IRadio: radio interface
- RadioPhone: phone radio implementation
- Main: program entry point
- RadioPhoneTest: JUnit tests

## Features
- AM/FM bands
- Preset stations
- Interchangeable implementations

## Notes
JUnit tests were implemented and executed using Eclipse.
